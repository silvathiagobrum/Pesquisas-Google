# Pesquisas Google

Laboratório de Buscas — Detetives da Contabilidade.

Apresentação interativa com 17 slides, quizzes, casos investigativos e dossiê A4 em PDF no último slide.

As respostas ficam apenas no navegador do aluno (localStorage). Não são enviadas ao repositório.

Abra `index.html` ou acesse o GitHub Pages. O PDF em branco pode ser baixado no encerramento; respostas preenchidas podem ser impressas ou salvas em PDF pelo navegador.
